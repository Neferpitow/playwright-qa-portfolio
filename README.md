# 🚀 Playwright QA Portfolio - SauceDemo

Welcome to my test automation portfolio! This repository demonstrates my skills in **Quality Assurance (QA)** using modern tools like **Playwright** and **TypeScript**.

## 🛠️ Technologies Used
* **TypeScript**
* **Playwright Test**
* **VS Code**

## ⚙️ How to Run the Tests

1. Clone the repository:
   ```bash
   git clone [https://github.com/Neferpitow/playwright-qa-portfolio.git](https://github.com/Neferpitow/playwright-qa-portfolio.git)
   cd playwright-qa-portfolio
   2. Install dependencies:
   npm install
   2. Run the tests:
   npx playwright test --ui
